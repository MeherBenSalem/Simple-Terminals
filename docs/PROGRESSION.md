# From your first chest to a quantum network

OmniVault is built to grow with a world: useful on day one with nothing but vanilla materials, and still
the strongest storage you can build once you have nether stars to spare.

## Early game: vanilla materials only

No Omnium, no power, no Nether trip.

| Build | What it gives you |
| --- | --- |
| **Storage Hub** + **Inventory Cable** | The Tom's-Simple-Storage experience: place a hub, run inventory cable past your chests, barrels and drawers, and every inventory they touch shows up in one searchable terminal. Double chests count once. |
| **Storage Terminal** / **Crafting Terminal** | Iron, glass, redstone and a chest (plus a crafting table). Search, sort, take and store across every connected chest; craft straight from storage. |
| **Copper Vault** | 45 slots with an animated lid and a sort button, from copper and a chest. |
| **Drawers** (1×1, 1×2, 2×2) | Bulk storage for a few item types, with the item and count shown on the front. |
| **Leather Backpack** | 27 slots you can wear, place and dye. |
| **Trash Can** | Voids anything, from automation too. |

A Storage Hub network deliberately can't use storage cells, autocrafting or wireless terminals. When you want
those, swap the hub for a Nexus Core: your cables, terminals and chests keep working.

## Mid game: Omnium

Omnium Dust comes from amethyst, nether quartz and redstone; mixed with iron and smelted it becomes Omnium
Ingots, which go into Logic and Advanced Processors.

| Build | What it gives you |
| --- | --- |
| **Nexus Core** | The full network: no channel limits, optional Forge Energy. |
| **Cell Drive** + **4K–256K cells** | Compact storage that doesn't need chests; fluid cells for fluids. |
| **Import / Export / Storage Buses**, **Network Port** | Automation with any mod's machines, pipes and inventories. |
| **Destructor**, **Constructor**, **Signal Emitter**, **Storage Monitor** | Mine, place, react to stock levels and show counts on a wall. |
| **Wireless Terminal** + **Wireless Transmitter** | Your whole base from anywhere nearby. |
| **Autocrafting** | Patterns, Pattern Providers, Assemblers and Crafting Processors craft anything on request, sub-ingredients included. |
| **Iron → Diamond Vaults** and **Backpacks**, **Backpack Upgrades** | More slots, plus pickup, magnet, feeding, restock, compacting, crafting, void and more. |
| **Compacting Drawer**, **Drawer Controller**, drawer upgrades | Ore-processing friendly bulk storage. |
| **Linked Vault** and **Linked Pouch** | Ender-style shared storage on a colour frequency, across dimensions. |
| **Relocator** | Move a full chest or machine without emptying it. |

## Late game: quantum

| Build | What it gives you |
| --- | --- |
| **1M, 16M and Singularity cells** | A Singularity cell holds 2,147,483,648 items of up to 1,024 types (or 536 million buckets of fluid). |
| **Quantum Bridge** pairs | Join two parts of a network across any distance and between dimensions: a Nether outpost on your main network, your mining base wired to your vault. Entangle them with a Quantum Link Card. |
| **Quantum Assembler** | Crafts sixteen times as much per cycle as an Assembler, before Speed Upgrades. |
| **Quantum Wireless Terminal** | Your network from any distance, in any dimension. |
| **Netherite and Omnium Vaults**, **Netherite Backpack** | 135–162 blast-proof vault slots; 120 fire-proof backpack slots. |
| **Netherite Relocator**, netherite drawer upgrades | Tools that never wear out; drawers sixteen times bigger. |
| **Creative cells** | Practically bottomless, for creative and modpack makers. |
